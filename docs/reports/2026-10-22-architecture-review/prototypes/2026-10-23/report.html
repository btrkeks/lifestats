Operation identity, ordering and restore


SQLite effect/receipt transactions, persisted queues, file reopen and backup restoration were executed. Schedules are deterministic, with no concurrent writers or process-kill proof.


Stable operation IDs replay additive writes without rebinding them to a new server generation. Conditional edits still check a generation-bearing version. Clock revisions and unchecked authority changes can both revive stale content.








Complete scope refreshes with correct validators


Complete replacement removed deleted cached rows and preserved the pending queue. Actual loopback HTTP returned a body-free 304 for unchanged views. A representation-aware validator refreshed a today-sensitive view at day rollover.


URL-specific cache keys prevent borrowing another scope's validator. A database version alone misses time-dependent output and restore generations. No bandwidth, battery or latency benefit was measured.
